# Fat Cat Travels 🐱✈️

**Travel Management. Purrrfectly Planned. Effortlessly Enjoyed.**

A modern, responsive travel-themed homepage for Fat Cat Travels - your ultimate travel management companion.

## Features

- 🗺️ **Smart Itinerary Planning** - Organize trips with intuitive planning tools
- 🏨 **Booking Management** - Keep all bookings in one centralized location
- 💰 **Budget Tracking** - Monitor expenses and stay within budget
- 📱 **Mobile Ready** - Access plans anywhere, anytime
- 👥 **Collaboration** - Share itineraries with travel companions
- 🌍 **Discover Experiences** - Find attractions and hidden gems

## Features Included

### Responsive Design
- Mobile-first approach
- Works seamlessly on all devices
- Smooth animations and transitions

### Sections
1. **Navigation Bar** - Sticky header with easy navigation
2. **Hero Section** - Eye-catching introduction with floating animation
3. **Features Grid** - 6 key features with hover effects
4. **Destinations** - Popular travel categories
5. **Call-to-Action** - Engagement section
6. **Footer** - Links and social information

- Smooth scrolling navigation
- Hover animations on cards

- Active nav link highlighting
- Floating card animations
